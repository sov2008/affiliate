# CRO Funnel Gatekeeper Skill

## 1. Назначение
Скилл обеспечивает строгий технический надзор за всеми конверсионными ссылками и точками перехода на смартлинк монетизации (`/go`). Гарантирует целостность атрибуции трафика, соблюдение требований поисковых систем (Google/Bing) по рекламным ссылкам и защиту от несанкционированных утечек PageRank.

---

## 2. Критерии проверки конверсионных воронок
1. **Обязательные атрибуты безопасности (Affiliate Safety Disclosure):**
   - Каждая ссылка на `/go` обязана иметь:
     * `rel="nofollow sponsored"` (или комбинацию с `noopener noreferrer`).
     * `target="_blank"` (открытие партнерского оффера в новой вкладке без потери контекста блога).
2. **Параметры аналитики и трекинга (UTM & Attribution Parameters):**
   - Запрещены «голые» ссылки `/go` без параметров.
   - В каждой ссылке должны присутствовать параметры:
     * `source` — идентификатор компонента (`sticky_radar`, `sidebar_ad`, `inline_quiz`, `footer`, `independence_manifest` и т.д.).
     * `trigger` (или `trigger_source`) — точка соприкосновения (`classified_ad`, `unmasked_bar`, `manifesto_cta`).
     * `intent` — пользовательское намерение (`verify_match`, `bot_check`, `verified_singles`).
3. **Сквозная атрибуция сессии (Session CID Inheritance):**
   - Наличие клиентского скрипта, динамически подставляющего `cid` из `sessionStorage` (`flirtcheck_cid`) в query string ссылки непосредственно перед кликом.
4. **Запрет манипуляций (Anti-Deceptive Pattern):**
   - Категорически запрещены фейковые терминалы взлома, фиктивные счетчики обнаруженных шпионов и синтетические генераторы конверсий. Все предупреждения должны носить аналитический, фактурный характер.

---

## 3. Команда валидации (Funnel Verification Execution)

Для проверки скомпилированных страниц или исходных компонентов запустите:
```bash
npx tsx scripts/verify-cro-funnel.ts
```

Скрипт анализирует скомпилированные `.html` страницы в `blog/dist/` (а при их отсутствии — исходные `.astro` файлы), парсит все теги `<a>` с адресом `/go`, проверяет атрибуты и параметры, возвращая `exit 0` при 100% валидности или `exit 1` при наличии дефектов.
