# AI Gateway Invoker Skill

## Назначение
Обеспечивает генерацию высококачественных SEO-статей для блога с глубокой семантической проработкой и нативной конверсионной связкой под проверку профилей.

## Интеграция
- Сервис: `core/src/services/blogGenerator.service.ts`
- Шлюз моделей: `Groq (compound-mini)`, `Gemini 1.5 Flash`, `Qwen 2.5 72B`.

## Структурные требования к контенту
1. **Frontmatter (YAML)**:
   - `title`: броский H1 заголовок, содержащий целевой ключ дейтинг-тематики.
   - `description`: мета-описание для поисковых сниппетов (140–160 символов).
   - `pubDate`: дата публикации в формате `YYYY-MM-DD`.
   - `author`: "FlirtCheck Editorial Team".
   - `tags`: список тематических тегов.
   - `keywords`: список релевантных LSI-ключей.
2. **Основное тело (Markdown)**:
   - Введение с ярким крючком (hook).
   - 3–4 раздела с подзаголовками H2 и H3.
   - Практические нумерованные чек-листы и примеры диалогов.
   - Блок FAQ с вопросами и ответами для Schema.org `FAQPage`.
   - Нативные CTA-блоки проверки профиля (`/go` / FlirtCheck Smartlink).
