Managing URL Tracking Parameters

In digital marketing and analytics, URL parameters (such as standard UTM parameters or custom tracking IDs) are often passed from a landing page's URL down to Call-to-Action (CTA) links.

Conceptual Workflow

  1. Parameter Extraction: When a user arrives on a page, JavaScript extracts the query parameters present in window.location.search.
  2. URL Construction: Using the standard URL API, target URLs are safely parsed to append or update parameters without breaking existing query strings.
  3. DOM Update: The modified URLs are written back to the respective href attributes of designated links.

Implementation Example

document.addEventListener("DOMContentLoaded", function() {
    // 1. Capture query parameters from the current page URL
    const currentParams = new URLSearchParams(window.location.search);
    
    // Define the parameters you want to pass along
    const trackingKeys = ['click_id', 'sub1', 'sub2', 'sub_id'];

    // 2. Select the target links (e.g., links with a specific class)
    const targetLinks = document.querySelectorAll('a.trackable-link');

    targetLinks.forEach(link => {
        try {
            // Parse the link's existing destination URL
            const targetUrl = new URL(link.href);

            // 3. Append parameters if present in the page URL
            trackingKeys.forEach(key => {
                if (currentParams.has(key)) {
                    targetUrl.searchParams.set(key, currentParams.get(key));
                }
            });

            // Update the element's href attribute
            link.href = targetUrl.toString();
        } catch (e) {
            console.error("Invalid URL encountered:", link.href);
        }
    });
});

Best Practices & Security Considerations

  • Input Validation: When capturing parameters from the URL and reflecting them into the DOM or downstream requests, ensure inputs are sanitized to prevent Potential Cross-Site Scripting (XSS) vulnerabilities.
